# Ariztía – Sitio web de cafetería

Trabajo final de la materia **Programación I**.
Sitio web de una cafetería de especialidad de estilo moderno y minimalista,
desarrollado desde cero con HTML, CSS y JavaScript, sin frameworks ni gestores de contenido.

## Sitio publicado

https://sapatiri-dot.github.io/ariztia/

## Tecnologías

- **HTML5**: estructura semántica (`header`, `nav`, `main`, `section`, `article`, `figure`, `footer`).
- **CSS3**: Grid, Flexbox, variables CSS, media queries, transiciones y pseudo-elementos.
- **JavaScript (vanilla)**: manipulación del DOM y eventos.
- **Google Fonts**: Playfair Display e Inter.
- **Git y GitHub Pages**: control de versiones y deploy.

## Funcionalidades

- Diseño **responsive** (computadora, tablet y celular).
- **Menú filtrable** por categoría: café, frío y pastelería.
- **Formulario de reserva** con validación (campos vacíos, email válido y fecha no pasada).
- **Menú hamburguesa** para pantallas chicas.
- Botón para **volver arriba**.
- **Mapa de Google** incrustado en el pie de página.
- Galería de fotos con descripción (`figure` y `figcaption`).

## Estructura del proyecto

```
ariztia/
├── index.html      Estructura y contenido
├── style.css       Estilos y diseño responsive
├── script.js       Interactividad

├── sitemap.xml     Mapa del sitio

```

## Cómo ejecutarlo en local

1. Clonar el repositorio:
```
   git clone https://github.com/sapatiri-dot/ariztia.git
```
2. Abrir la carpeta en Visual Studio Code.
3. Clic derecho sobre `index.html` → **Open with Live Server**
   (o abrir `index.html` directamente en el navegador).

No requiere instalar dependencias ni compilar.

## Deploy

El sitio se publica con **GitHub Pages** desde la rama `main`, carpeta raíz.
Cada cambio subido al repositorio se publica automáticamente en uno o dos minutos.
